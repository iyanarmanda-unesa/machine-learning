# Machine Learning

## Usage

Copy or fork this repository, then:

### Installation

1. Virtual Environment Initialitation
    
    Windows:

    ```sh
    python -m venv venv
    ```

    macOS / Linux:

    ```sh
    python3 -m venv venv
    ```

2. Virtual Environment Activation

    Windows:

    ```sh
    venv\Scripts\activate

    # or

    .\venv\Scripts\Activate.ps1
    ```

    macOs / Linux:

    ```sh
    source venv/bin/activate
    ```

    Deactivation virtual environment:

    ```sh
    deactive
    ```

3. Library Installation

    *In inside of `venv`*

    ```sh
    pip install <python_library>
    ```

    > See **python script libraries** list

### Running Scripts

*In inside of `venv`*

```sh
python <python_script_path>
```

> See **Python Script path** list
